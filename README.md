# Complaint Privacy System

## Overview

Complaint Privacy System is a JavaScript-based web application developed to provide a secure and confidential platform for submitting and managing complaints. The system focuses on protecting user privacy while enabling administrators to efficiently monitor, review, and resolve complaints.

The project follows the MVC architecture and is built using NODE.JS,EXPRESS,MONGODB,EJS,JAVASCRIPT.

---

## Features

- Secure user registration and login
- Submit complaints through an easy-to-use interface
- Privacy-focused complaint management
- View complaint details and status
- Administrator panel for managing complaints
- Database integration using JDBC
- Responsive web interface
